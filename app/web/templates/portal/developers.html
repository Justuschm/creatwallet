Pass per API ausgeben

curl -X POST {{ base }}/api/v1/passes \
  -H "Authorization: Bearer wk_…" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: bestellung-4711" \
  -d '{"template_id": "VORLAGEN-ID",
       "data": {"name": "Anna Beispiel"}}'

Die Antwort enthält page_url – den Link für deinen Kunden – und download_url für die Datei selbst. Mit Idempotency-Key entsteht bei Wiederholung kein zweiter Pass.
